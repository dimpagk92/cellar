# docs/archive

Session-specific artifacts from past work. Kept for historical reference and git-blame navigation; not part of the current documentation surface.

Move something here when:
- It was written as a session handoff, merge audit, or one-time summary.
- Its information is frozen in time (dated benchmarks, one-off migration notes).
- Newcomers grokking the architecture should NOT have to read it.

Do NOT move here:
- Docs referenced by active code paths, runbooks, or CI.
- Design docs for features still in development.
- Changelogs or security-policy documents still informing rollout decisions.
